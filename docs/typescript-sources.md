# TypeScript Sources

Every TypeScript entry was checked against at least one published source before it went in, and its `source`
field names the primary one. This page lists the URLs. Only pages that were opened and read are cited. Where a
source contradicted the premise of a smell, the entry was rewritten to match it, and those cases are noted in
the tables.

Claims about compiler behaviour and runtime output were also checked by running them, with `tsc` 5.9 in
`--strict` mode and Node 26. The `typescript:` range on each entry was set from the release notes, or from the
first published `lib.*.d.ts` that carries the API the fix needs.

## The reference shelf

The sources cited most often, beyond the official documentation:

- Dan Vanderkam, *Effective TypeScript*, 2nd ed. (O'Reilly, 2024). Items cited by number, checked against the
  "Things to Remember" in the book's repository: https://github.com/danvk/effective-typescript
- Kyle Simpson, *You Don't Know JS: Types & Grammar*: https://github.com/getify/You-Dont-Know-JS
- Google TypeScript Style Guide: https://google.github.io/styleguide/tsguide.html
- typescript-eslint rules: https://typescript-eslint.io/rules/ and ESLint rules: https://eslint.org/docs/latest/rules/
- MDN Web Docs: https://developer.mozilla.org/
- TypeScript handbook and release notes: https://www.typescriptlang.org/docs/
- Node.js documentation and guides, including "Don't Block the Event Loop":
  https://nodejs.org/en/learn/asynchronous-work/dont-block-the-event-loop
- React documentation, including "You Might Not Need an Effect": https://react.dev/learn/you-might-not-need-an-effect

  https://jakearchibald.com/2017/await-vs-return-vs-return-await/
